# 夜航者 Demo Night · 活动报名页

海报风活动报名 demo（纯前端）。

## 约定

- 活动：夜航者 Demo Night（自拟 demo 文案）
- 报名字段：姓名、邮箱、备注
- 提交后：成功页 + 模拟确认邮件提示（不接真实邮件服务）
- 风格：大胆色块、大标题、活动海报感

## 本地预览

```bash
npx --yes serve . -l 4173
```

打开 http://127.0.0.1:4173

## 自测清单

- [ ] 姓名为空 / 过短会拦截
- [ ] 邮箱格式错误会拦截
- [ ] 提交后出现确认回执与邮箱提示
- [ ] 手机宽度可正常阅读与提交
